# Список литературы по дисциплинам лаборатории

**Лаборатория математики ФН1**

Основная литература обязательна для подготовки к экзамену, дополнительная —
для углублённого изучения и научной работы. Все указанные издания есть
в научной библиотеке университета.

## Математический анализ

**Основная**

1. Фихтенгольц Г. М. Курс дифференциального и интегрального исчисления :
   в 3 т. — Москва : Физматлит, 2003.
2. Кудрявцев Л. Д. Курс математического анализа : в 3 т. — Москва :
   Высшая школа, 2006.
3. Демидович Б. П. Сборник задач и упражнений по математическому анализу. —
   Москва : АСТ, 2010.

**Дополнительная**

4. Зорич В. А. Математический анализ : в 2 ч. — Москва : МЦНМО, 2019.
5. Рудин У. Основы математического анализа. — Москва : Мир, 1976.
6. Полиа Г., Сегё Г. Задачи и теоремы из анализа : в 2 ч. — Москва : Наука, 1978.

## Как пользоваться

- Готовясь к экзамену, держитесь основного списка: вопросы билетов
  сформулированы по нему.
- Дополнительная литература нужна для курсовых, докладов и олимпиад.
- Ссылки на источники в письменных работах оформляйте по ГОСТ Р 7.0.100–2018
  (см. раздел «Шаблоны»).
