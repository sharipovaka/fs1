## Задача 1. Операции над множествами

Даны множества $A = \{x \in \mathbb{Z} : |x| \le a\}$, $B = \{x \in \mathbb{Z} : 0 < x < b\}$,
$C = \{x \in \mathbb{Z} : x = 3k,\ k \in \mathbb{Z}\}$.

Найти $(A \cup B) \setminus C$, $A \cap B \cap C$ и симметрическую разность $A \triangle B$.
Изобразить результат на диаграмме Эйлера — Венна.

## Задача 2. Доказательство тождества

Доказать тождество двумя способами — через определение принадлежности элемента
и с помощью диаграмм:

$$(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B).$$

## Задача 3. Бинарные отношения

На множестве $M = \{1, 2, \dots, n\}$ задано отношение
$R = \{(x, y) : x - y \text{ кратно } m\}$.

Проверить рефлексивность, симметричность, антисимметричность и транзитивность.
Является ли $R$ отношением эквивалентности? Если да, выписать классы эквивалентности.

## Задача 4. Комбинаторика

Сколькими способами можно составить команду из $k$ человек, если в группе
$n$ студентов, причём двое из них не могут работать вместе?
Ответ обосновать, приведя схему рассуждения.

## Задача 5. Графы

Граф задан матрицей смежности (см. файл вариантов). Требуется:

1. изобразить граф;
2. определить степени всех вершин, проверить лемму о рукопожатиях;
3. найти все компоненты связности;
4. выяснить, является ли граф эйлеровым и гамильтоновым;
5. построить остовное дерево методом поиска в ширину.

## Задача 6. Булевы функции

Для функции, заданной вектором значений варианта, требуется:

1. построить таблицу истинности;
2. записать СДНФ и СКНФ;
3. минимизировать функцию с помощью карты Карно;
4. проверить принадлежность функции классам $T_0$, $T_1$, $S$, $M$, $L$.
