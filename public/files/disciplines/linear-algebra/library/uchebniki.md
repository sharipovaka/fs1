# Учебники и задачники: Линейная алгебра и аналитическая геометрия

**Лаборатория математики ФН1**

## Основная литература

1. **Кострикин А. И.** Введение в алгебру : в 3 ч. — Москва : МЦНМО, 2018.
   *Основной учебник. Часть 1 покрывает почти весь семестровый курс.*
2. **Ильин В. А., Позняк Э. Г.** Линейная алгебра. — Москва : Физматлит, 2010.
   *Классический втузовский учебник, ближе всего к программе кафедры.*
3. **Проскуряков И. В.** Сборник задач по линейной алгебре. — Санкт-Петербург : Лань, 2008.
   *Задачник курса, источник заданий типовых расчётов.*

## Дополнительная литература

4. **Гантмахер Ф. Р.** Теория матриц. — Москва : Физматлит, 2010.
   *Справочник по матричному анализу, нужен для курсовых.*
5. **Хорн Р., Джонсон Ч.** Матричный анализ. — Москва : Мир, 1989.
   *Современный взгляд, полезен при работе с численными методами.*

## Совет

Линейная алгебра плохо усваивается чтением: почти каждое утверждение
стоит проверить на матрице 2×2 или 3×3 руками. Задачник Проскурякова
для этого удобнее учебника.
