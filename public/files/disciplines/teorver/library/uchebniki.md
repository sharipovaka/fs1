# Учебники и задачники: Теория вероятностей и математическая статистика

**Лаборатория математики ФН1**

## Основная литература

1. **Гмурман В. Е.** Теория вероятностей и математическая статистика. — Москва : Юрайт, 2020.
   *Основной учебник. Есть парный задачник того же автора с решениями.*
2. **Вентцель Е. С.** Теория вероятностей. — Москва : Юстиция, 2018.
   *Понятное изложение с инженерными примерами.*
3. **Сборник задач по теории вероятностей** / под ред. А. В. Прохорова. — Москва : Наука, 1986.
   *Задачник курса.*

## Дополнительная литература

4. **Ширяев А. Н.** Вероятность : в 2 кн. — Москва : МЦНМО, 2011.
   *Строгое изложение на языке теории меры, для тех, кто идёт в науку.*
5. **Феллер В.** Введение в теорию вероятностей и её приложения. — Москва : Мир, 1984.
   *Много содержательных примеров, классика жанра.*

## По разделам курса

| Раздел | Где читать |
| --- | --- |
| Случайные события, формула Байеса | Гмурман, гл. 1–4 |
| Случайные величины и распределения | Вентцель, гл. 5–8 |
| Предельные теоремы | Гмурман, гл. 9; Ширяев, кн. 1 |
| Математическая статистика | Гмурман, гл. 15–19 |

## Совет

Задачи по теорверу чаще решаются неверно из-за неправильно выбранной
вероятностной модели, а не из-за арифметики. Прежде чем считать,
выпишите пространство элементарных исходов.
