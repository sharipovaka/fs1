# Лекция 4. Формула Тейлора

**Лаборатория математики ФН1** · математический анализ, семестр 1

## Постановка

Пусть функция $f$ определена в окрестности точки $a$ и имеет в этой точке
производные до порядка $n$ включительно. Тогда

$$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + o\big((x-a)^n\big),\quad x \to a.$$

Это разложение с остаточным членом **в форме Пеано**.

Если дополнительно $f$ имеет производную порядка $n+1$ на интервале между $a$ и $x$,
остаток записывается **в форме Лагранжа**:

$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1},\qquad \xi \in (a, x).$$

## Опорные разложения при $x \to 0$

| Функция | Разложение |
| --- | --- |
| $e^x$ | $1 + x + \dfrac{x^2}{2!} + \dots + \dfrac{x^n}{n!} + o(x^n)$ |
| $\sin x$ | $x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \dots + o(x^{2n})$ |
| $\cos x$ | $1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dots + o(x^{2n+1})$ |
| $\ln(1+x)$ | $x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \dots + o(x^n)$ |
| $(1+x)^\alpha$ | $1 + \alpha x + \dfrac{\alpha(\alpha-1)}{2!}x^2 + \dots + o(x^n)$ |

## Типичная ошибка

При вычислении предела отношения нельзя обрывать разложения числителя
и знаменателя на разных порядках малости. Сохраняйте члены до одного
и того же порядка — иначе результат окажется неверным.

## Разобранный пример

$$\lim_{x\to 0}\frac{\sin x - x\cos x}{x^3} = \frac{1}{3}.$$

Действительно,

$$\sin x = x - \frac{x^3}{6} + o(x^3),\qquad x\cos x = x - \frac{x^3}{2} + o(x^3),$$

откуда числитель равен $\dfrac{x^3}{3} + o(x^3)$.
