# Учебники и задачники: Дискретная математика

**Лаборатория математики ФН1**

## Основная литература

1. **Новиков Ф. А.** Дискретная математика. — Санкт-Петербург : Питер, 2019.
   *Основной учебник курса, покрывает все разделы программы.*
2. **Гаврилов Г. П., Сапоженко А. А.** Задачи и упражнения по дискретной математике. — Москва : Физматлит, 2005.
   *Задачник, из которого берутся задания типового расчёта.*

## Дополнительная литература

3. **Грэхем Р., Кнут Д., Паташник О.** Конкретная математика. — Москва : Вильямс, 2010.
   *Комбинаторика и суммы, написано живо; полезно для олимпиад.*
4. **Оре О.** Теория графов. — Москва : Наука, 1980.
   *Классика по графам, читается легко.*

## По разделам курса

| Раздел | Где читать |
| --- | --- |
| Множества и отношения | Новиков, гл. 1–2 |
| Комбинаторика | Новиков, гл. 3; Грэхем, гл. 5 |
| Теория графов | Новиков, гл. 6; Оре |
| Булевы функции | Новиков, гл. 4 |

## Связь с другими курсами

Материал прямо используется в курсах алгоритмов и структур данных.
Если что-то кажется абстрактным, посмотрите, как это применяется
в задачах на графах и в анализе сложности алгоритмов.
