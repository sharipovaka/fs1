Список литературы по дисциплинам лаборатории

Лаборатория математики ФН1

Основная литература обязательна для подготовки к экзамену, дополнительная — для углублённого изучения и научной работы. Все указанные издания есть в научной библиотеке университета.

Как пользоваться

  • Готовясь к экзамену, держитесь основного списка: вопросы билетов сформулированы по нему.
  • Дополнительная литература нужна для курсовых, докладов и олимпиад.
  • Ссылки на источники в письменных работах оформляйте по ГОСТ Р 7.0.100–2018 (см. раздел «Шаблоны»).
