Числовые данные вариантов — в файле tr-01-varianty.csv.

Задача 1. Операции над множествами

Даны множества A={x∈ℤ:|x|≤a}A = \{x \in \mathbb{Z} : |x| \le a\}, B={x∈ℤ:0<x<b}B = \{x \in \mathbb{Z} : 0 < x < b\}, C={x∈ℤ:x=3k,k∈ℤ}C = \{x \in \mathbb{Z} : x = 3k,\ k \in \mathbb{Z}\}.

Найти (A∪B)\C(A \cup B) \setminus C, A∩B∩CA \cap B \cap C и симметрическую разность A△BA \triangle B. Изобразить результат на диаграмме Эйлера — Венна.

Задача 2. Доказательство тождества

Доказать тождество двумя способами — через определение принадлежности элемента и с помощью диаграмм:

(A\B)∪(B\A)=(A∪B)\(A∩B).(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B).

Задача 3. Бинарные отношения

На множестве M={1,2,…,n}M = \{1, 2, \dots, n\} задано отношение R={(x,y):x−y кратно m}R = \{(x, y) : x - y \text{ кратно } m\}.

Проверить рефлексивность, симметричность, антисимметричность и транзитивность. Является ли RR отношением эквивалентности? Если да, выписать классы эквивалентности.

Задача 4. Комбинаторика

Сколькими способами можно составить команду из kk человек, если в группе nn студентов, причём двое из них не могут работать вместе? Ответ обосновать, приведя схему рассуждения.

Задача 5. Графы

Граф задан матрицей смежности (см. файл вариантов). Требуется:

  1. изобразить граф;
  2. определить степени всех вершин, проверить лемму о рукопожатиях;
  3. найти все компоненты связности;
  4. выяснить, является ли граф эйлеровым и гамильтоновым;
  5. построить остовное дерево методом поиска в ширину.

Задача 6. Булевы функции

Для функции, заданной вектором значений варианта, требуется:

  1. построить таблицу истинности;
  2. записать СДНФ и СКНФ;
  3. минимизировать функцию с помощью карты Карно;
  4. проверить принадлежность функции классам T0T_0, T1T_1, SS, MM, LL.

Требования к оформлению

  • все диаграммы и графы вычерчиваются аккуратно, вершины подписываются;
  • в задаче 4 обязательно словесное обоснование комбинаторной схемы;
  • в задаче 6 карта Карно приводится полностью, с выделенными областями склеивания.
