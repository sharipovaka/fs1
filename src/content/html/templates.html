Шаблоны работ

Единые заготовки для отчётов, курсовых и выпускных работ. Использование шаблонов обязательно: работы, оформленные иначе, возвращаются на доработку без проверки содержания.

Доступные шаблоны

Шаблон Формат Назначение Статус
Титульный лист DOCX, PDF Все виды письменных работ актуален
Отчёт по лабораторной работе DOCX Численные методы, теория вероятностей актуален
Курсовая работа LaTeX (coursework.tex) 3–4 курс, все направления актуален
Отчёт по практике DOCX Учебная и производственная практика обновляется
Вычислительный отчёт Jupyter (report.ipynb) Задания с программной реализацией актуален
Презентация к докладу Beamer, PPTX Семинары и конференции актуален

Требования к оформлению

  • шрифт основного текста — Times New Roman, 14 pt, полуторный интервал;
  • поля: левое 30 мм, правое 15 мм, верхнее и нижнее по 20 мм;
  • нумерация страниц сквозная, внизу по центру; титульный лист не нумеруется;
  • формулы набираются в редакторе формул или LaTeX, нумеруются в круглых скобках справа;
  • рисунки подписываются снизу, таблицы — сверху;
  • список литературы оформляется по ГОСТ Р 7.0.100–2018.

Заготовка LaTeX

Минимальная преамбула для курсовой работы:

\documentclass[14pt, a4paper]{extarticle}

\usepackage[T2A]{fontenc}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\usepackage[left=30mm, right=15mm, top=20mm, bottom=20mm]{geometry}
\usepackage{amsmath, amssymb, amsthm}
\usepackage{graphicx}
\usepackage{setspace}

\onehalfspacing
\theoremstyle{plain}
\newtheorem{theorem}{Теорема}[section]
\newtheorem{lemma}[theorem]{Лемма}

\begin{document}
\input{title}          % титульный лист из отдельного файла
\tableofcontents
\newpage

\section{Постановка задачи}
% ...

\begin{thebibliography}{9}
  \bibitem{fikhtengolts} Фихтенгольц Г.\,М. Курс дифференциального
    и интегрального исчисления. --- М.: Физматлит, 2003.
\end{thebibliography}
\end{document}

Заготовка Jupyter Notebook

Структура вычислительного отчёта — чередование текстовых и кодовых ячеек:

  1. Титульная ячейка (Markdown): тема, ФИО, группа, руководитель.
  2. Постановка задачи: математическая формулировка с формулами в LaTeX.
  3. Метод решения: описание алгоритма и оценка его сложности.
  4. Реализация: код с комментариями, без «магических чисел».
  5. Численный эксперимент: таблицы и графики сходимости.
  6. Выводы: сопоставление с теоретической оценкой погрешности.

Готовый ноутбук сдаётся вместе с HTML-версией, полученной командой:

pandoc report.ipynb -t html -s -o report.html
Где взять файлы Архив со всеми шаблонами выложен в системе электронного обучения университета в разделе кафедры. Печатные образцы титульных листов доступны на стенде у аудитории 312.
