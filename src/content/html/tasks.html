Типовой расчёт № 2 «Производная и её приложения»

Каждый вариант содержит шесть задач. Ниже приведён образец (вариант 1).

  1. Найти производную функции, заданной неявно уравнением x³ + y³ − 3axy = 0
  2. Вычислить предел по правилу Лопиталя: limx→0 (tg x − x) ⁄ (x − sin x)
  3. Разложить функцию f(x) = ln(1 + 2x) по формуле Маклорена до члена порядка x⁴ включительно и оценить остаток при |x| ≤ 0,1.
  4. Провести полное исследование функции и построить её график: f(x) = x³ ⁄ (x² − 1)
  5. Найти наибольшее и наименьшее значения функции f(x) = x·e−x на отрезке [0; 3].
  6. Прикладная задача. Из круглого бревна радиуса R выпиливается балка прямоугольного сечения. Определить размеры сечения, при которых момент сопротивления W = bh²⁄6 максимален.

Требования к оформлению решения

  • работа выполняется от руки на листах А4 или в LaTeX по шаблону лаборатории;
  • условие каждой задачи переписывается полностью;
  • решение должно содержать обоснование, а не только цепочку преобразований;
  • ответ выделяется отдельной строкой;
  • графики строятся на координатной сетке с указанием масштаба и характерных точек.

Задания повышенной сложности

Для желающих участвовать в олимпиадах в лаборатории еженедельно публикуется задача недели. Решения принимаются в письменном виде до пятницы; авторы лучших решений получают дополнительные баллы к рейтингу и приглашение в олимпиадную сборную.

Задача недели. Докажите, что для любой непрерывной на отрезке [0; 1] функции f, удовлетворяющей условию f(0) = f(1), найдётся такое c ∈ [0; 1⁄2], что f(c) = f(c + 1⁄2).
