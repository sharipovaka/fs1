Лекция 4. Формула Тейлора

Пусть функция f определена в окрестности точки a и имеет в этой точке производные до порядка n включительно. Тогда справедливо разложение с остаточным членом в форме Пеано:

f(x) = f(a) + f′(a)(x − a) + f″(a)(x − a)²⁄2! + … + f⁽ⁿ⁾(a)(x − a)ⁿ⁄n! + o((x − a)ⁿ), x → a

Если дополнительно f имеет производную порядка n+1 на интервале между a и x, остаточный член записывается в форме Лагранжа:

Rn(x) = f⁽ⁿ⁺¹⁾(ξ)(x − a)ⁿ⁺¹⁄(n + 1)!, ξ между a и x

Опорные разложения при x → 0

Функция Разложение по формуле Маклорена
ex 1 + x + x²⁄2! + x³⁄3! + … + xⁿ⁄n! + o(xⁿ)
sin x x − x³⁄3! + x⁵⁄5! − … + o(x2n)
cos x 1 − x²⁄2! + x⁴⁄4! − … + o(x2n+1)
ln(1 + x) x − x²⁄2 + x³⁄3 − … + o(xⁿ)
(1 + x)α 1 + αx + α(α − 1)x²⁄2! + … + o(xⁿ)
Типичная ошибка. При вычислении предела отношения нельзя обрывать разложения числителя и знаменателя на разных порядках малости: сохраняйте члены до одного и того же порядка, иначе результат окажется неверным.

Пример практического вычисления

Найдём предел, используя разложения до x³:

limx→0 (sin x − x·cos x) ⁄ x³ = 1⁄3

Действительно, sin x = x − x³⁄6 + o(x³), а x·cos x = x − x³⁄2 + o(x³). Разность равна x³⁄3 + o(x³), откуда и следует ответ.

Лекция 5. Численная проверка (фрагмент ноутбука)

В конспектах, подготовленных в Jupyter, теоретические выкладки сопровождаются вычислительными экспериментами. Ниже — ячейка из ноутбука по теме: 

import numpy as np

def taylor_sin(x, n_terms=5):
    """Частичная сумма ряда Маклорена для sin(x)."""
    k = np.arange(n_terms)
    terms = (-1) ** k * x ** (2 * k + 1) / np.vectorize(np.math.factorial)(2 * k + 1)
    return terms.sum()

for x in (0.1, 0.5, 1.0, 2.0):
    approx, exact = taylor_sin(x), np.sin(x)
    print(f"x={x:4.1f}  ряд={approx:.10f}  sin={exact:.10f}  ошибка={abs(approx-exact):.2e}")
Важно Ряд Маклорена сходится к sin x при любом x, однако при больших |x| для достижения машинной точности требуется значительно больше слагаемых, а промежуточные величины растут — на практике аргумент предварительно приводят к отрезку [−π, π].

Как готовятся эти материалы

Исходный конспект пишется в Markdown или Jupyter Notebook и конвертируется командой:

pandoc notebook.ipynb -t html -s -o notebook.html

Полученный файл кладётся в src/content/html/, импортируется в компонент подраздела и отображается на сайте внутри рамки материала.
